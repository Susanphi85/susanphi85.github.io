## 🛠️ Technical Information (For the Curious)

If you're wondering how this works under the hood, here's a simple explanation:

The software uses **Zstandard** (zstd) — a modern compression algorithm known for being both fast and powerful. It combines this with **columnar encoding**, which means it looks at data column by column to find repeating patterns. This is especially effective with tabular data like spreadsheets.

It also uses **schema fingerprinting**, which automatically detects the structure of your data. This allows the tool to optimize how it compresses based on what it finds. The entire engine runs on **WebAssembly**, which is how it achieves desktop-level performance right inside your browser.
